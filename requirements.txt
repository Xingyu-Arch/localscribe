# localscribe v0.1.1 默认组合（Windows / Linux，Python 3.9~3.12）
#
# 为什么锁这个组合（2026-11-26 根因已定位）：
#   ctranslate2 4.6+ / onnxruntime 1.22+ 用 VS2022 编译，需要 VC++ 运行库 14.40+。
#   旧运行库（如 14.28）上会直接闪退（0xC0000005，没有任何 Python 报错）。
#   4.5.0 / 1.19.2 是 VS2019 编译的，新旧运行库都能跑，所以作为默认组合，
#   保证「装完就能用」。
#
#   想用最新版（测试者已验证：ct2 4.9.1 + ort 1.32.0 + numpy 2.5.5 + VC++ 14.44）：
#   1) 先装 VC++ 运行库 14.40+：https://aka.ms/vs/17/release/vc_redist.x64.exe
#   2) pip install "ctranslate2==4.9.1" "onnxruntime==1.32.0"
#   `python localscribe.py --doctor` 会显示当前 msvcp140.dll 版本。
#
# 注意：ctranslate2 4.5.0 没有 Python 3.13/3.14 的 Windows 轮子，
#       请用 Python 3.12（推荐）或 3.9~3.11。
faster-whisper==1.2.1
ctranslate2==4.5.0
onnxruntime==1.19.2
# ct2 4.5.0 需要 pkg_resources，setuptools 81 起已移除它
setuptools<81

imageio-ffmpeg>=0.5.0
numpy>=1.24,<3
