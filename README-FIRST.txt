localscribe 本地视频转文字 —— 新手先看我
==========================================

这个工具做什么：
把视频、音频里的说话声转成文字。全程在你自己的电脑上跑，
不收费、不注册、不上传。转好的文字是 txt 文件。

----------------------------------------------------------
第 1 步：装 Python 3.12（已经装过的跳过）
----------------------------------------------------------
1. 打开 https://www.python.org/downloads/
2. 点黄色的 "Download Python 3.12.x" 按钮。
3. 运行下载好的安装包。安装界面最下面有一个选项：
      [ ] Add python.exe to PATH
   一定要勾上它！然后点 "Install Now"，等装完，关掉。
4. 本版不支持 Python 3.13 / 3.14，请装 3.12（64 位）。
   如果电脑里已经有别的版本，不影响，装 3.12 就行。

----------------------------------------------------------
第 2 步：安装 localscribe
----------------------------------------------------------
1. 双击 setup.bat。
2. 窗口会滚很多字，是在下载运行环境，正常，等它跑完。
3. 如果出现这一句：
      Install GPU libraries now? [y/N]:
   - 有 NVIDIA 显卡（RTX / GTX 开头）：输入 y，按回车。
     会多下载约 1.3 GB，转写快很多。
   - 没有 NVIDIA 显卡，或者不确定：直接按回车。
     用 CPU 也能转，只是慢一些。
4. 看到 "Setup complete." 就装好了，按任意键关闭窗口。
5. 如果出现 [ERROR]，先截图，再双击 CHECK.bat 把结果也截图，
   一起发到 GitHub 的 Issues（下载页面有入口）。

----------------------------------------------------------
第 3 步：转写
----------------------------------------------------------
1. 把视频/音频文件拖到 run.bat 的图标上，松开鼠标。
   可以一次拖多个文件。
2. 会弹出黑色窗口显示进度，等它跑完。
3. 转好的文字在视频旁边，文件名相同，后缀是 .txt。
   例如：视频.mp4 → 视频.txt

----------------------------------------------------------
常见问题
----------------------------------------------------------
问：双击 run.bat 没反应 / 窗口一闪就没了？
答：不要直接双击，要把视频文件拖到 run.bat 上。
    如果拖了还是闪退，双击 CHECK.bat，把窗口内容截图发出来。

问：提示 Python not found？
答：第 1 步没做，或者安装时没勾 "Add python.exe to PATH"。
    重新运行 Python 安装包，选 Modify，把那个选项勾上；
    或者卸载重装，安装时记得勾选。

问：提示 Unsupported Python version？
答：你装的是 3.13/3.14。请装 Python 3.12（64 位），
    然后把文件夹里的 .venv 文件夹删掉，再双击 setup.bat。

问：转写很慢？
答：没有 NVIDIA 显卡时 CPU 本来就慢（1 小时视频可能要 1~3 小时）。
    有 N 卡的话，重新双击 setup.bat，问 GPU 库时按 y。

问：第一次运行等很久？
答：第一次要下载模型（约 0.5~1.6 GB，看有没有显卡），有进度条；
    下载过一次以后就不需要再下了。

问：文字里有错字？
答：正常。重要内容请自己校对，或者用更大的模型：
    .venv\Scripts\python.exe localscribe.py 视频.mp4 --model medium

问：想检查电脑环境？
答：双击 CHECK.bat，它会打印一份检查结果。

问：想卸载？
答：直接删掉整个 localscribe 文件夹即可，不写注册表、不装服务。
    模型缓存在 C:\Users\你的用户名\.cache\huggingface，
    想彻底清掉可以一起删。
